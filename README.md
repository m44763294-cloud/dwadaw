# Portals: входящие офферы

Скопируйте `.env.example` в `.env`, укажите `BOT_TOKEN` от @BotFather и запустите `run.bat`.
В личном чате с ботом отправьте `/start`, затем `/token ВАШ_PARTNER_API_КЛЮЧ`, затем `/offers`.

Бот отвечает только после ввода команды `/portaisgobot` в личном чате: до неё на любые сообщения (включая `/start`) бот молчит. Список открытых команд у бота намеренно не содержит `/portaisgobot`, а состояние доступа живёт в памяти процесса и сбрасывается при перезапуске.

Показывается самый высокий активный оффер на каждый подарок. Нажатие «Принять» открывает подтверждение с суммой; только следующая кнопка выполняет продажу. Portals проверяет, что сумма не изменилась. Комиссия удерживается площадкой.

Ключ хранится только в памяти процесса и исчезает при перезапуске или команде `/forget`. Сообщение с ключом бот пытается удалить, но удаление может не сработать. Telegram-боты не являются секретными чатами: используйте только своего бота и доверенный компьютер. Partner API ключ даёт права на покупку, продажу и вывод, держите его в секрете и перевыпускайте при утечке.

`/offers` загружает первую страницу до 100 подарков; уведомлений и автоматического мониторинга нет. Точный результат при сетевой ошибке после подтверждения может быть неизвестен — проверьте Portals перед повтором. Бесплатный тариф Portals ограничен 1 запросом в секунду.
